## 작성법

- 파일 이름은 `NNNN-kebab-case.md`다.
  번호는 네 자리이고, 쓴 순서대로 붙인다.
  번호는 다시 쓰지 않는다.
- ADR 한 편은 반 페이지 안팎으로 쓴다.
- 첫 줄 `# ADR NNNN: 제목` 아래에 `확인 기준 커밋`과 `상태` 줄을 둔다.
- 본문은 `## 맥락`, `## 결정`, `## 결과` 순서다.
  - 맥락: 결정 전에 무엇이 있었는가.
  - 결정: 무엇을 하기로 했는가. 확인한 사실에는 근거(`파일:심볼` 또는 명령)를 적는다.
  - 결과: 결정 뒤에 무엇이 남았는가. 아직 모르는 것은 "미확인"으로 적는다.
- 상태는 `제안`, `채택`, `대체됨(ADR NNNN)` 중 하나다.
- 이미 채택한 ADR은 고치지 않는다. 바뀌면 새 ADR을 쓰고 이전 것의 상태를 `대체됨`으로 바꾼다.
- 마지막 줄은 `Decided in: <epic id>`다.
